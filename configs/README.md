# Configuration policy

The four YAML files in this directory are transcriptions of final-method interfaces and hyperparameters. They are deliberately marked non-runnable until linked to a frozen input manifest, implementation and tested output. The nearby historical YAML files are not copied because several are smoke configurations or describe a different architecture.

Each accepted configuration will record the manuscript-method section, schema version, random seed, runtime version, input SHA-256 values, output paths and a human-readable change log.
